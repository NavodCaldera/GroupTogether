- (decision) No cash back to buyers ever; late/duplicate payments become tokens; holding money is not a concern (owner)
- (decision) Keep premium brands; delete group carts, slips, packing/warehouse/lots, samples, stock offers, owner chat; delete old rules incompatible with agent model
- (override) Agent model supersedes same-day group basket decisions (48h fill, 20k minimum, owner lock, 6h window, Option A, cart/basket split)
- (decision) Q1: basket under LKR 50,000 waits at most 5 months, then ships anyway with GroupBasket paying the courier cost (challenged: conflicts with factory-time promise; owner to confirm)
- (override) Q1 corrected by owner: maximum wait is 2 months (not 5); under LKR 50,000 at 2 months ships anyway, GroupBasket pays the courier cost
- (decision) Buyer pays first; only a paid item joins the agent's basket for that factory
- (decision) When the agent marks the order arrived, the buyer has 48 hours to collect it from the agent and to file any return request
- (decision) Q2: factory is paid weekly; items whose 48-hour collect/return window closed are totalled up to Saturday 11:59 pm and that amount is paid to the factory account
- (override) Q2/Q3 clarified: factory earns an item once 48 hours pass after the agent receives it (collected or not); earned amount shows on the factory dashboard; totals up to Saturday 11:59 pm are deposited to the factory account every Sunday
- (decision) Q4: agent keeps uncollected parcels without time limit; no forfeit, no tokens (risk noted: agent storage fills up)
- (decision) Q5: agent area is a 1 km radius around the agent (~3.1 km2); no two agents within 2 km of each other
- (decision) Q6: before paying, buyer selects an agent; default is the nearest agent (distance shown), buyer can change to any agent; exclusive area only controls where agents may be placed
- (decision) Q7: agents are paid LKR 20 per item in tokens only, no cash transfer; they spend tokens on the platform or transfer them to another buyer who pays them cash outside the platform
- (assumption) Agent earns the item's tokens when marking it received, credited every Sunday with factory payouts (owner did not state timing)
- (decision) Q8: every user can transfer tokens to any other user (risk noted: off-platform cash scams GroupBasket cannot resolve)
- (decision) Q9: agent security deposit is given back as tokens (transferable to buyers/agents for cash outside the platform); GroupBasket makes cash payments only to factories, never to other stakeholders
- (override) Courier fee factory-to-agent is paid by the agent; GroupBasket reimburses that amount as tokens to the agent's profile (replaces Q1 'GroupBasket pays courier' wording)
- (decision) A full token system is required: buyer late/duplicate credits, agent per-item pay, deposit return, courier reimbursement, user-to-user transfers
- (decision) Q10: agent pays the LKR 200,000 deposit through PayHere; held locked while active; returned as tokens when the agent leaves, minus losses such as missing parcels
- (assumption) Agent pays the PayHere fee on the deposit (owner did not state)
- (decision) Q11: buyer files return online within 48h; hands item to an agent only after admin or factory accepts; buyer is told which agent, and that agent's dashboard lists the return parcel to collect; agent sends it back to the factory; buyer gets full-price tokens only for factory-side faults
- (decision) Q12: factory-fault return tokens are credited when the agent marks the return parcel collected from the buyer
- (decision) Q13: after an accepted return the buyer has 7 days to hand the item to the agent; otherwise the return is cancelled, no tokens, and the factory is paid for that item the following Sunday
- (assumption) An item with an open return is excluded from the factory's Sunday payout until the return is decided or cancelled
- (decision) Q14: admin books the courier from factory to agent after a basket locks and the factory packs, entering driver details; the agent pays the driver on arrival and is reimbursed in tokens
- (decision) Q15: admin gets the fee from the courier service and enters it when booking; agent confirms on arrival and is reimbursed exactly that amount in tokens
- (decision) Q16: basket locks automatically when it reaches LKR 50,000; a new basket for that agent and factory opens immediately
- (assumption) A buyer's whole paid order goes into the open basket even if it pushes the total past LKR 50,000; orders are never split across baskets
- (decision) Q17: agents apply online (NIC, own photo, address and pin, storage photos); admin checks the 2 km rule and approves; then they pay the deposit and go live
- (decision) Q18: buyer shows a 6-digit pickup code; agent types it and sees the list of items to hand over, then marks collected
